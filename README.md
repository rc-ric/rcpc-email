# RCPC Interview Invitation — HTML Email Guide

Responsive, table-based HTML email templates built with inline CSS to ensure consistent dark-mode rendering across Gmail, Outlook, and mobile mail clients. Each file is pre-configured by interview date.

---

## How to Send via Gmail

Standard email compose windows treat raw HTML tags as plain text. Use the browser copy-paste method below to preserve the layout, colors, and inline styles:

1. **Select the Date File:** Locate the `.html` file corresponding to the applicant's scheduled interview date on your computer.
2. **Open in Browser:** Double-click the `.html` file to open it in your web browser (Chrome, Firefox, Edge, or Brave). You will see the fully formatted, dark-themed email design.
3. **Select & Copy:** Click anywhere inside the browser window, press **`Ctrl + A`** (or `Cmd + A` on macOS) to select the entire rendered design, and press **`Ctrl + C`** (`Cmd + C`) to copy it.
4. **Paste into Gmail:** Open a new **Compose** window in Gmail, click into the body of the email, and press **`Ctrl + V`** (`Cmd + V`) to paste. Gmail will retain the underlying tables and inline CSS perfectly.

> **Tip:** When sending a batch invite for a specific date, place all recipient email addresses in the **BCC** field so applicants cannot see each other's addresses.
